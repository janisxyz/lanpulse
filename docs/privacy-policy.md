## Short version

LanPulse does **not** collect, sell, share, or transmit personal data. There is no account, analytics, ads, or cloud backend. Scan results, custom names, theme, language, and optional SSH passwords stay on the phone. Android backup is off. Uninstall deletes them.

## Data we collect

Nothing off-device. `INTERNET` is used only to talk to hosts on attached LANs (ICMP, TCP, mDNS, SSDP, SSH).

## Data that stays on the device

Custom names, optional SSH credentials, language, and theme in app preferences. Scan results stay in memory while the app is open.

## Permissions

- Network — LAN probes and SSH
- Wi-Fi / nearby devices — SSID and link stats (`neverForLocation` on Android 13+)
- Location — Android requires it to read SSID on many versions; the app does not use GPS, does not track, and does not send location
- Multicast — mDNS hostnames

## Deletion

Clear app storage or uninstall. We hold no server-side copy, so we cannot delete anything remotely.

## Children

Not directed at children. No collection from anyone.
