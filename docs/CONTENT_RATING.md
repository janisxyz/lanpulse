# Play Console — Content rating (IARC)

Start the questionnaire. Category:

**Utility / Productivity / Other** (not a game, not social).

Answer **No** to all of the following:

- Violence
- Sexual content / nudity
- Language (profanity)
- Controlled substances (alcohol, tobacco, drugs)
- Gambling (including simulated)
- User-generated content that is not moderated
- Shares user location
- Digital purchases / in-app purchases
- Ads
- Users can communicate with each other (chat, voice, social)

Port scanning and SSH are **local admin tools**, not user-to-user chat. SSH is a connection the user starts to a machine they already have credentials for.

Misc:

- App collects user location: **No** (SSID only, not shared)
- Age-restricted: **No**

Expected rating: **Everyone** / PEGI 3 / USK 0.

Apply the rating to the app when IARC emails the certificate (it also appears in Console).
