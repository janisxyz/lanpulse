# Play Console — Content rating (IARC)

Questionnaire category: **Utility / Productivity / Other**

Answer **No** to:

- Violence
- Sexual content
- Language
- Controlled substances
- Gambling
- User-generated content that is not moderated
- Shares user location
- Digital purchases
- Ads
- Users can communicate

Port scanning and SSH are local admin tools, not user-to-user chat.

Expected rating: **Everyone** / PEGI 3.
